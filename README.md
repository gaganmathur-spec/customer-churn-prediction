# 👥 Customer Churn Prediction

📊 A **Machine Learning project** that predicts whether a customer is likely to **churn or stay** using customer data.

🎯 **Objective:** Identify customers at higher risk of leaving and help businesses improve **customer retention**.

✨ **Key Features:**

* 🤖 Logistic Regression model
* 📊 Data preprocessing and analysis
* 📈 Model evaluation
* 💡 Churn risk identification
* 🌐 Streamlit web application

🛠️ **Built With:** 🐍 Python • 🐼 Pandas • 🔢 NumPy • 🤖 Scikit-learn • 🌐 Streamlit
